# LCDM · CCB Ⅱ 制动显示屏交互仿真

一个不依赖任何框架或构建工具的 LCDM 教学仿真网页。直接打开 `index.html` 即可使用。

## 设备布局

- 左侧三枚实体背光键：增亮、减亮、自动亮度
- 屏幕下方八枚软键：F1–F8，屏幕上方的功能文字会随页面动态变化
- 键盘 F1–F8 与实体软键等效；`Esc` 关闭弹层；`?` 打开操作指南
- 双指针压力表：
  - 左表：均衡风缸 ER（白针）+ 列车管 BP（红针）
  - 右表：总风缸 MR（白针）+ 制动缸 BC（红针）
- 左栏流量表、本机/补机状态、机车号、实时时钟与日期

## 软键功能

| 键 | 主界面功能 | 说明 |
| --- | --- | --- |
| F1 | 执行 | 确认当前修改并生效；无修改时提示当前设置已生效 |
| F2 | 存储 | 保存当前参数，并打开事件记录 / 故障履历 |
| F3 | 电空制动 | 进入操纵端、列车管、车辆模式、补风设置菜单 |
| F4 | 操纵端 | 本机（操纵端）/ 补机（非操纵端）切换；补机自动切除列车管 |
| F5 | 列车管 | 投入 / 切除；补机端具有联锁保护 |
| F6 | 货车 / 客车 | 切换定压：货车 500 kPa，客车 600 kPa |
| F7 | 补风 / 不补风 | 切换列车管漏风自动补风策略 |
| F8 | 退出 | 返回上一级 / 主界面；有未执行修改时放弃修改 |

修改 F4–F7 后先进入琥珀色“待执行”状态，按 F1 才会真正生效，按 F8 取消。设置页内 F3 可将待执行参数恢复为出厂默认。

## 其他功能

- 教员台：制动缓解、常用制动、紧急制动工况注入，环境光模拟，实时压力与最近操作
- 自动 / 手动背光，自动模式跟随环境光
- 参数持久化到浏览器 `localStorage`
- 事件记录、故障履历、分页、未读标记、参数存储次数
- 响应式布局，支持桌面、平板与手机
- 恢复出厂设置、全屏、按键音开关

## 说明

本项目为 CCB Ⅱ 制动显示屏教学仿真，不可替代实车设备，不用于实际行车操作。
