    LCDM 操作指南

    屏幕下方 F1–F8 是随页面变化的软键，按键功能显示在屏幕对应位置。键盘 F1–F8 与实体键等效。

    01主界面软键

    F1执行
    确认待执行修改，保存设置并立即生效
    F2存储
    存储当前参数，打开事件记录 / 故障履历
    F3电空制动
    进入制动核心设置菜单
    F4操纵端
    本机（操纵端）/ 补机（非操纵端）切换
    F5列车管
    投入 / 切除；补机端自动联锁切除
    F6货车 / 客车
    切换定压：货车 500 kPa，客车 600 kPa
    F7补风 / 不补风
    列车管漏风时是否自动补风
    F8退出
    返回上一级；有未执行修改时放弃并取消

    02按键与状态

    先修改，再执行

    按 F4–F7 后，设置先进入琥珀色“待执行”状态。按 F1 才会写入并生效；按 F8 放弃全部未执行修改。

    本机 / 补机联锁

    切为补机时，列车管自动切除；补机端不能执行“列车管投入”。切回本机后可按 F5 再次投入。

    03左侧背光键

    ☀＋增亮☀−减亮AUTO自动亮度

    自动亮度跟随环境光传感器。可在“教员台”中调整模拟环境光，观察亮度变化。

    提示 软键功能会随主界面、电空制动设置、记录查询页面动态变化。
    SYSTEM RESET

    恢复出厂设置？

    操纵端、列车管、车辆模式、补风、背光、工况和全部记录都将恢复初始状态。此操作不可撤销。
